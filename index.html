How photo deletion works with your device's Photo Gallery
📸
Live Camera (Zero Gallery Clutter):

When using Take Photo, the photo is captured directly into browser memory. It is never saved to your device's photo gallery in the first place, leaving your gallery 100% clean.

💻
Desktop Files (Physical Disk Deletion):

On Chrome/Edge desktop, selecting a photo via the File System Access API allows the app to physically delete the original file from your disk once exported.

📱
Mobile Gallery (Browser Sandbox Security):

Apple iOS and Android security sandboxes intentionally forbid all web browsers from modifying or deleting existing photos in Apple Photos or Google Photos. (Direct gallery deletion on mobile requires a native app wrapper like Capacitor).
